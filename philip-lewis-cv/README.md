# Philip Jon Echavez Lewis CV

Local A4 CV artifact for browser review and PDF export.

## Open Locally

Open `index.html` in a browser, or use the local file URL:

```text
file:///Users/philiplewis/archestimator/philip-lewis-cv/index.html
```

The page includes an `Export / Print PDF` button that opens the browser print flow.

## Export PDF

From this folder:

```sh
node export-pdf.mjs
```

The script writes:

```text
Philip-Jon-Echavez-Lewis-CV.pdf
```

## Format Notes

- A4 portrait, two-page professional CV.
- Reverse-chronological experience.
- Real HTML text for accessible reading order and searchable/selectable PDF output.
- No portrait photo by default, to keep the CV broadly international and ATS-safe.
- Sources used: old resume PDF and the pitch deck Founder Fit / Founder CV slides.
