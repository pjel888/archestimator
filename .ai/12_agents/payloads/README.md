# Agent Payloads

Model-specific instruction payloads go here. Do not fork core policy; reference `.ai/00_system/` instead.

Active payloads should cover the current agent bench: Claude, Codex, OpenCode, CommandCode, Gemini, Kimi, and DeepSeek. Kimi should be considered a strong frontend/product UI lane as well as a long-context synthesis lane. Ollama is intentionally not an agent payload because the only approved active Ollama use is the nomic embedding model used by ChunkHound.
