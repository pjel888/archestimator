# Tasks

## Current Authority

The canonical current state is `.ai/10_state/current-state.md`. Read only its
FAST PATH first, then search the specific task area. A file under
`.ai/03_plans/` becomes current only when the user, current state, or an active
manifest explicitly names it.

Do not restore deleted prototype surfaces from old boards, handoffs, or archive
material. Expand implementation only through the current request, an in-session
Brief, or an explicitly active Plan Pack.

## Task Artifacts

Direct work needs no task file. Brief work keeps the outcome, scope, sequence,
evidence, and stop condition in-session. Create a durable task board only when
an active Plan Pack or coordinated multi-owner workflow needs one.

A durable board contains the smallest sufficient Task Contract:

- objective and explicit non-goals;
- owned units and dependencies;
- exact acceptance evidence and test decision;
- authorization, stop, retry, and escalation conditions.

When multi-agent work is selected, use
`.ai/08_prompts/000_Planning Prompts/Multi-Agent-Execution-Directive.md`.
