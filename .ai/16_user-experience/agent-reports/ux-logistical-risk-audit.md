# UX And Logistical Risk Audit

Date: 2026-06-22

Scope note: Source-and-test-based audit of user-visible Archestimator workflows for logistical errors, ambiguous states, missing empty/error/loading/success states, confusing wording, destructive flows, privacy/access edges, accessibility signals, and likely closed-beta friction. Evidence came from application source and Vitest tests only; browser automation was not run because the requested claims are supported by static source/test evidence.

## Coverage Notes And Uncertainty

- Positive coverage found: login/auth error text is intentionally sanitized (`src/lib/auth/error-mapping.ts`, `tests/vitest/auth-error-mapping.test.ts`); terms acceptance is explicit and tested (`src/components/workshop/TermsAcceptancePanel.tsx`, `tests/vitest/terms-acceptance-panel.test.tsx`); project and estimate deletion have preview, typed confirmation, rollback, and audit-oriented tests (`tests/vitest/bulk-destructive-preview-modal.test.tsx`, `tests/vitest/mass-deletion-contract.test.ts`, `tests/vitest/mass-deletion-ui-contract.test.ts`).
- Shared-link collaboration surfaces appear comparatively strong in source: comments and decisions include loading/error/retry/confirmation states (`src/components/share/SharePageComments.tsx`, `src/components/share/SharePageDecision.tsx`). This audit did not include live browser verification of the share page.
- Navigation, auth, project creation, project list/grouping, shared publication, beta feedback, project details, and estimate table workflows were sampled from source and tests. The audit did not cover every export/proposal preview path, every settings subflow, or provider/runtime behavior.
- Browser automation was intentionally skipped because the requested report is source/test-based and the issues above are visible in static code and Vitest assertions. Responsive layout and actual screen-reader behavior remain follow-up validation areas after fixes.
- Severity is beta-product severity, not security severity. Items marked Medium are likely to affect closed-beta comprehension, privacy management, or accidental data loss, but no source evidence showed an immediate backend data-corruption defect in the audited paths.
