## Coverage notes and uncertainty
- Coverage is strong on source + tests for core functional flows: project grouping/workspace navigation, estimate list bootstrap, tree DnD, row mutation/version-history, component insert/replace, collaboration security/presence, and version-control activity API.
- Gaps/uncertainty:
  - Full-screen end-to-end cross-user concurrent editing is only covered by targeted hooks/integration-style tests, not browser multi-client simulation.
  - Some UI behavior (especially cursor overlay positioning and keyboard tree interactions) is inferred from component contracts and a subset of tests.
  - Named-version UX (create/restore/compare) is intentionally scoped by existing code as dormant in Activity; this may leave user discoverability risk.
