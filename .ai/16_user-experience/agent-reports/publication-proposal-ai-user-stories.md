# Publication Proposal AI User Stories

**Date:** 2026-06-22  
**Scope note:** Public share/publication pages, share-link security/session/comments, unsubscribe/activity/workspace shell, proposal export/workbook/hosted export paths, charts/data insights/map/location workflows, and AI ask/package-builder/audit flows. Scope excludes internal admin tooling and non-user-facing API internals.

## Coverage notes and uncertainty

- Coverage is strongest for API contracts, security hardening, and core export/AI endpoint behavior (`project-publication-*`, `proposal-export-route`, `ai-*` tests).
- UX-level behavior on the rendered public pages exists but is only partially asserted in integration tests; several interaction branches (token expiry guidance, retry flows, and edge-case consent messaging) appear sparsely covered.
- Several inferred “As a” outcomes are reconstructed from route/component intent and test contracts; no direct end-to-end browser acceptance scripts were identified for the full user journey.
- Uncertainty remains around copy quality and error recovery UX language for recipient flows because visible copy assertions are light in the current tests.
