# Prompt Templates

Reusable prompt shells for audits, planning, product strategy, estimation
checks, implementation handoffs, release proof, and agent-framework dry-runs.

Current framework library:

- `agent-workflow-template-library.md` - compact templates for feature plans,
  implementation, bug/debug, hotfix, release, review, provider proof, Notion
  mirror prep, GitHub ruleset prep, and dry-run evals.
