# Blockers Template

Copy this shape into a task folder's `BLOCKERS.md` only when the pass is blocked.

## Blocker summary

State the blocker in one sentence.

## Safety boundary or missing authority

Name the boundary: same-file conflict, missing provider credentials, missing target confirmation, destructive-risk approval, unavailable local infrastructure, repeated verification failure, or owner decision required.

## Evidence collected

List commands, files inspected, and exact output excerpts that prove the blocker.

## Recovery attempted

List safe attempts already made and why they did not resolve the blocker.

## Decision needed

Name the exact coordinator or owner decision required.

## Next safe action

Describe the next non-destructive action once the blocker is cleared.
