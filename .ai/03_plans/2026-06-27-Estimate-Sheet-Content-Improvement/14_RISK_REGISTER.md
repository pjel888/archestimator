# Risk Register

Severity and likelihood use High/Medium/Low. Residual risk is the expected remaining exposure after the proposed controls pass. "Owner" is the future implementation lane, not an assigned person.

| ID | Risk | Trigger | Severity | Likelihood | Affected Areas | Detection | Prevention | Contingency | Owner | Release Gate | Residual Risk | Status |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| R-001 | Global save state blocks unrelated row/tree actions and causes frozen-feeling UI. | Any long-running row/tree mutation while the user moves another row/component. | High | High | Row handlers, tree drops, move dialog, status UI | DOM/e2e slow-save scenarios, user telemetry for long action wait | Scoped row/node pending state; no sheet-wide move lock for unrelated actions | Feature-flag off coordinator if broad; keep old path only while security-equivalent | Frontend mutation lane | Row move after slow unrelated edit proof | Low if scoped locks pass; Medium without browser proof | Open |
