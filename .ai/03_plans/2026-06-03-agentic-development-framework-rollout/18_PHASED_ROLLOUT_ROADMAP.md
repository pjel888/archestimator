# Phased Rollout Roadmap

| Phase | Scope | Enforcement |
|---|---|---|
| 0 | Audit/current plan refinement | complete for this docs task |
| 1 | `.ai/00_system`, payloads, prompts, skills, thin adapters | docs/payload implementation |

If process slows urgent work, keep core preflight/evidence/no-secrets rules and roll back heavy checks to advisory.
