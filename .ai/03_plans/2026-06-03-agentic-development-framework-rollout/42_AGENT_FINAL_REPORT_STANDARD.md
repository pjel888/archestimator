# Agent Final Report Standard

Required fields:
- Status: READY_FOR_IMPLEMENTATION / NEEDS_HUMAN_DECISION / BLOCKED / COMPLETE as appropriate.
- Scope and non-goals.
- Files changed/created.
- Key decisions and proof boundaries.
- Bugs/blockers created.
- Commands run with exit codes.
- Graph/GitNexus/code-review-graph evidence.
- Validation evidence.
- Branch, commit hash, push status.
- Remaining owner decisions.
- Explicit statements of what was not implemented or not proven.

Never claim implementation, enforcement, provider proof, GitHub settings, Notion sync, or beta readiness without direct evidence.
