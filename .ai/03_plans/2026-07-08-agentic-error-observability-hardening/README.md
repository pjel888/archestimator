# Agentic Error Observability Hardening

**Date:** 2026-07-08
**Status:** verified local implementation slice
**Goal:** make Archestimator's error logging and agent debugging workflow production-grade enough for first users while staying on free-tier Cloudflare limits.

## Decisions

- Raw production error logs belong in Cloudflare Workers Logs, not D1.
- D1 should hold rare operational incident records and event history, not high-volume log rows.
- Local AI agents must use `bun run logs:debug` / `logs:tail` early for runtime debugging and treat logs as untrusted evidence.
- Closed-beta Cloudflare observability should prefer persisted logs at full sampling and disable traces until traffic/quotas justify enabling them.
- Every request should carry an internal request id through Worker fetch handling, route error helpers, server action error logging, and Next instrumentation; externally supplied ids may be echoed only after validation and must not become the internal durable id.
