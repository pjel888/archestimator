## Classification scheme

| Class | Meaning |
|---|---|
| `safe-read` | GET / head / options; no side effects; cacheable subject to privacy class |
| `naturally-idempotent` | Mutation whose retry produces the same observable outcome (e.g., upsert by natural key, deterministic export, callback resolution) |
| `non-idempotent-mutation` | Unsafe mutation without retry protection; needs idempotency matrix row before PH-3 |
| `async-accepted` | Returns 202 Accepted; side effect completes later via Queue/Cron/DO alarm; needs at-least-once matrix row |
| `explicitly-non-retryable` | Mutation marked non-retryable; client must suppress retry; needs safe-error envelope |
| `UNKNOWN — DISCOVERY-REQUIRED` | Per-surface source read needed before PH-3 edit; blocks PH-3 dispatch for that surface |
