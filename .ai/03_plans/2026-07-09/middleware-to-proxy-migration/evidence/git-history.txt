refactor(middleware): replace deprecated src/proxy.ts with Next.js middleware entrypoint

Context:
The OpenNext Cloudflare runtime uses src/middleware.ts as the Edge
middleware entrypoint; the legacy src/proxy.ts convention is no
longer honored and needs to be retired.

Changes:
- Delete src/proxy.ts and introduce src/middleware.ts as the canonical
  Edge middleware entrypoint.
- Simplify request-proxy session gating to delegate session/auth
  verification to the server layout using Better Auth cookies.
- Update auth-proxy and proxy-file-convention tests to import from
  @/middleware and assert the new delegation behavior.

Impact:
The application now follows the current Next.js/Cloudflare middleware
convention; deploy and source-smoke scripts no longer reference the
removed proxy file.
