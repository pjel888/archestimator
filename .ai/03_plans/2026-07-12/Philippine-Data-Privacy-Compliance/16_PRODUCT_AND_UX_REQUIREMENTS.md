# Product and UX Requirements

## Privacy Center

Create a user privacy center containing:

- current privacy notice;
- data categories;
- download request;
- correction request;
- deletion request;
- objection and consent controls;
- marketing preferences;
- analytics preferences;
- request status;
- DPO contact;
- complaint information.

## Collection-Point Disclosures

Provide concise just-in-time notices for:

- registration;
- invitation;
- public sharing;
- commenting;
- approval and decline;
- uploads;
- AI usage;
- support;
- analytics.

## Share and Client Review

Public and password-protected shares must:

- reveal only customer-selected data;
- use non-enumerable tokens;
- support expiry and revocation;
- avoid unnecessary recipient tracking;
- clearly disclose access-event processing;
- avoid search-engine indexing;
- prevent referrer leakage;
- support optional password and authenticated access;
- record owner-visible access only where lawful and disclosed.

## Collaboration

Invitation flows must:

- disclose who invited the person;
- state what workspace or project access means;
- avoid creating full accounts before acceptance unless necessary;
- expire invitations;
- allow withdrawal;
- minimize invitation telemetry;
- prevent account enumeration.

## Uploads

The UI must state:

- permitted file types;
- sensitivity warning;
- customer responsibility;
- who can access;
- retention;
- deletion behavior;
- virus-scanning limitations where applicable.

## Destructive Actions

Deletion UI must explain:

- soft delete versus permanent deletion;
- restoration window;
- legal hold;
- shared-client impact;
- retained audit data;
- backup aging;
- processor deletion.

## AI UX

AI interfaces must disclose:

- provider involvement;
- what data is sent;
- whether data is retained by provider;
- whether data is used for training;
- user control;
- review requirement;
- generated-output limitations.
