Avatar is a square (3px-radius) user/entity image that falls back to up to two initials. Square corners keep it aligned with the architectural radius scale (no circles).

```jsx
<Avatar src="/u/philip.jpg" alt="Philip Lewis" size="sm" />
<Avatar initials="PL" size="md" />
```
Sizes `xs|sm|md|lg` = 20/28/36/48px.
