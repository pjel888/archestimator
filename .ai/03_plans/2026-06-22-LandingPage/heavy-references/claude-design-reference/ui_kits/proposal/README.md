# Proposal UI kit — Client cost proposal

The client-facing document a finished estimate becomes. Token-only (no bundle dependency).

- **Review chrome** (paper panel above the document) — version + shared/password metadata and the client's decision loop: **Comment · Approve · Decline**.
- **The paper** — warm proposal paper `#FFFDF8`, Source Serif 4 body, clay logo, source-boundary rules. Firm/date/validity metadata, a formal proposal letter, a summary-of-cost BOQ table (group rows + total), inclusions/exclusions, terms, and a signature/conforme block.

This is deliberately *not* a dashboard — it reads as a document you would trust. Figures are illustrative (Lewis Residence, ₱ peso).
