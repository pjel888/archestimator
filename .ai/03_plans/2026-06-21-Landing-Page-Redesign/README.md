   walkthrough."**
3. **Scope = the full marketing system**: `/`, `/features`, `/pricing`, `/about`,

4. **Proof strategy = radical honesty.** A Live / Building / Planned claims ledger,

These are settled. Sibling docs design against them; none reopens them. Ratification items
(R1–R11 in MASTER §1) that these decisions lean on are tracked as ⚠️ GATED ON in `LOOP_LEDGER.md`.

## 4. Definition of 100 % (the completion gate)

The pack is **at 100 %** — the explicit goal of the audit-and-improve pass — when **all** of
the following hold (mirrors `MASTER-AUDIT-AND-SCORECARD.md` §6):

1. **Every doc scores 100 / 100 / 100** on the three audit axes (Strategy / Quality /
   Implementation Readiness). Re-score is logged in `MASTER-AUDIT-AND-SCORECARD.md` §7.
2. **Cross-link integrity = 100 %.** Every cross-doc link resolves to a canonical filename
   in `10-CANONICAL-DOC-MAP.md` §1. Verified by the grep in §4 of that doc.
3. **Every dimension in §3 above has an owning doc that exists and scores 100 / 100 / 100.**
4. **Every ⚠️ GATED ON item is either resolved or explicitly carried as an open owner
   decision in `LOOP_LEDGER.md`.** No gate is silently dropped.
5. **The 17 missing docs** (M-1 → M-17 in `MASTER-AUDIT-AND-SCORECARD.md` §4) **exist and
   score 100 / 100 / 100.**
6. **The 10 cross-cutting strategic gaps** (X-1 → X-10 in `MASTER-AUDIT-AND-SCORECARD.md`
   §5) **are closed** (each has an owning doc and a documented decision or owner-carried
   status).

When all six hold, the pack is implementation-ready: a competent implementer (Codex / human
dev) can pick up any doc and build exactly what it says without a clarifying conversation,
and the owner can sign off knowing every public word obeys MASTER §15.
