# Post-Cutover Full-App QA Ledger

## Master Goal

Prove that `https://archestimator.com` is usable on the Cloudflare-native runtime, with no active app/runtime dependency on Vercel, Supabase, or Resend, before recommending any further provider downgrade, cancellation, or removal.

This ledger supersedes stale pre-cutover wording in the original planning README for the current execution loop. It does not erase those earlier planning constraints; it records the later proof state and the remaining post-cutover QA work.
