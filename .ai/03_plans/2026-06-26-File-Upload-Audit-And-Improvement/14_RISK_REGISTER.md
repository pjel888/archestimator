## Risk Acceptance Notes

- Closed beta can tolerate server-mediated uploads for small current caps, but cannot tolerate unscanned downloads or tenant-isolation bypass for production.
- Public component image derivatives are acceptable only if product/security records that users will not upload sensitive/proprietary images for that derivative and accepts cache exposure risk.
- Any component-image public derivative exception must explicitly cover estimate-row project-component images and publication/share exposure, not only reusable library records.
- Malware scanning provider choice remains an explicit future decision gate before attachment approval/download rollout, not an assumption in this plan.
- Role owners above are planning owners. Future implementation should replace role owners with named owners in the implementation issue/PR tracker.
