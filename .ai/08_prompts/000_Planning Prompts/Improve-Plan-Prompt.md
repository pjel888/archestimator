# Improve A Plan Pack

## Load

Read `Frontier-Planning-Kernel.md`, applicable gates, this prompt, and
`Plan-Pack-Schema.md`. Load `Multi-Agent-Execution-Directive.md` only when the
pack delegates work.

## Objective

Make the pack smaller, clearer, current, and executable without changing the
accepted outcome or implementing product code.

## Method

1. Snapshot current source, Git state, manifest, and authoritative inputs.
2. Reconcile the Task Contract and every core requirement.
3. Remove stale paths, duplicated policy, speculative scope, ceremonial
   artifacts, unnecessary tests/agents/reviews, and false blockers.
4. Repair authority references, requirement-to-unit-to-evidence traceability,
   ownership, handoffs, recovery, and the dependency DAG.
5. Resolve contradictions and ordinary decisions from current evidence.
6. Keep compatibility or release machinery only for proven current obligations.
7. Run one criterion-based challenge pass, refresh hashes last, and validate.

## Completion

Report files removed or consolidated, material repairs, first ready unit, and
fresh validation. Readiness depends on executable truth, not scores, reviewer
identity, or artifact count.
