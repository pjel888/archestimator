# Improve A Plan Pack

## Load

Read `Frontier-Planning-Kernel.md`, applicable gates, this prompt, then
`Plan-Pack-Schema.md`.

## Objective

Make the pack smaller, clearer, current, and executable without changing the
accepted outcome or implementing product code.

## Method

1. Snapshot current source, Git state, pack manifest, and authoritative inputs.
2. Remove stale paths, duplicate prose, speculative scope, ceremonial artifacts,
   unnecessary tests/agents/reviews, and false blockers.
3. Resolve contradictions and ordinary decisions from current evidence.
4. Repair requirement-to-unit-to-evidence traceability and the dependency DAG.
5. Keep compatibility/release machinery only for proven current obligations.
6. Run one criterion-based challenge pass and repair actual failures.
7. Refresh hashes last and run the pack validator.

## Completion

Report files removed/consolidated, material repairs, first ready unit, and fresh
validation. Do not use scores, reviewer identity, or artifact count as readiness.
