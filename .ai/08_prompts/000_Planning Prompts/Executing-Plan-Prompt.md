# Execute A Plan Pack

## Load

Read `Frontier-Planning-Kernel.md`, applicable gates, this prompt, then
`Plan-Pack-Schema.md`.

## Objective

Implement the full authorized repository outcome, integrate it, verify every
core requirement, update durable truth, and archive only when complete.

## Method

1. Inspect current goal, Git state, manifest, canonical implementation plan, and
   first ready unit.
2. Repair stale plan state locally; do not return routine repair to the owner.
3. Build the minimal live dependency graph. Use one writer per shared file;
   formal leases only for actual concurrent contention.
4. For each unit: reread current source, decide, implement the smallest coherent
   slice, run authorized evidence, inspect the diff, and update status.
5. Integrate by dependency boundary and rerun only invalidated evidence.
6. Audit every original requirement, decision, boundary, risk, cleanup item, and
   deliverable against current artifacts.
7. Update canonical state and archive only after the archived copy validates.

## Execution Rules

- Alpha/pre-beta: direct replacement and fix-forward are defaults.
- Internal dependencies, stale artifacts, optional tools/reviewers, memory, and
  unapproved tests are continuation work, not blockers.
- Tests/build/browser/visual QA require explicit current-task user authorization.
- Preserve unrelated work; do not branch, commit, push, deploy, or mutate
  prohibited external state without exact authority.
- Continue while safe implementable work remains.

## Final Report

Return terminal status, changed files, requirement-to-evidence result, provider
boundary if any, validation performed, and real remaining risk.
