Last updated: 2026-06-18 (code-reconciled — statuses verified against current codebase)

---

## Purpose

This document enumerates the 20 canonical happy-path user journeys for Archestimator. Each journey is broken into a step-by-step matrix covering user action, system response, data lifecycle, UI feedback, error/recovery alternates, success metrics, evidence required, and current status.

The journeys cover the full product surface — from first visit through collaborative workflows, AI-assisted estimation, shared reviews, and failure recovery. Every journey must be walkthrough-validated before beta.
