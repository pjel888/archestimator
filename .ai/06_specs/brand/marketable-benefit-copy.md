## Benefit copy cards

### 1. Never Start From Zero

**Short copy:**

Create cost estimates faster by starting from an organized project structure instead of rebuilding every sheet from scratch.

**Longer copy:**

Archestimator keeps your estimate organized by project, area, scope, and cost component, so you spend less time setting up files and more time pricing the work.

**Alternate titles:**

- Stop Rebuilding Estimates
- Start Ahead
- Faster Estimate Setup
- Build From What You Know

### 2. Reuse What Repeats

**Short copy:**

Save repeat work with a cost component library you can reuse across estimates and projects.

**Longer copy:**

Turn common products, assemblies, services, labor patterns, and scope packages into reusable components. Bring them into new estimates or projects, then adjust them for the specific proposal.

**Alternate titles:**

- Reusable Cost Library
- Reuse Cost Components
- Build Once, Reuse Often
- Reusable Cost Logic

### 3. Your Numbers Hold Up

**Short copy:**

Keep estimate revisions traceable, so important cost data does not disappear into old spreadsheet copies.

**Longer copy:**

Estimates change. Archestimator keeps estimate sheets, revisions, supplier context, and assumptions inside the project so you can see what changed without hunting through file names and duplicated spreadsheets.

**Alternate titles:**

- Trace Every Change
- Defend Every Number
- No More File Confusion
- Protect Estimate History

### 4. Compare Every Option

**Short copy:**

Create multiple estimates under one project and compare different cost proposals side by side.

**Longer copy:**

Use separate estimates for alternates, revisions, value-engineering options, or different proposal schemes. Keep every option connected to the same project so comparison stays clear.

**Alternate titles:**

- Compare Cost Proposals
- Compare Estimate Sheets
- Option Comparison
- Side-by-Side Proposals

### 5. Show Clients the Difference

**Short copy:**

Use visual breakdowns to show clients what changed, where the cost moved, and why one proposal costs more than another.

**Longer copy:**

Instead of walking clients through rows of a spreadsheet, show cost differences by area, discipline, revision, or proposal option. Make trade-offs easier to understand before decisions are made.

**Alternate titles:**

- Visual Cost Clarity
- Explain the Difference
- Client-Ready Comparisons
- Cost Stories Clients Understand

### 6. Keep Costs in Place

**Short copy:**

Organize costs by project structure, area, scope, and discipline so every line item has a clear place.

**Longer copy:**

Archestimator follows how AEC teams already think: projects have areas, trades, scopes, suppliers, components, quantities, assumptions, and revisions. The estimate stays easier to navigate because the structure mirrors the work.

**Alternate titles:**

- Project-Shaped Estimates
- Organized by Scope
- Every Cost Has a Place
- Estimate by Area and Trade

## Copy guardrails

- Retain **Component Library** as the internal/product feature name. In public landing copy, keep the name when it helps product recognition, and add a plain-language explanation when needed: reusable cost components, repeated assemblies, or reusable cost logic.
- Say “revisions stay traceable” or “your numbers hold up,” not “never lose data,” because absolute data-loss claims are risky.
- Say “helps explain cost differences,” not “clients will approve faster.”
- Use “compare options” when space is tight; use “compare cost proposals” when the section needs specificity.
- Keep “data visualization” user-facing as “visual breakdowns” or “show cost differences.”
- Do not feature AI as a current capability.
- Do not claim we invented reusable estimating intelligence or that we are the only tool that does it.
