# Canonical Multi-Agent Workflow Adapter

Use `AGENTS.md`, `.ai/00_system/AGENT_OPERATING_PROTOCOL.md`, the Validation
Matrix, and
`.ai/08_prompts/000_Planning Prompts/Multi-Agent-Execution-Directive.md` as the
complete semantic workflow.

1. Establish the parent Task Contract and select Direct, Brief, or Plan Pack.
2. Build an acyclic dependency graph and choose the fewest useful capability
   lanes through `.ai/12_agents/codex-role-model-matrix.json`.
3. Resolve native subagents, parallel threads, emulated passes, or single-agent
   fallback without changing contracts or fabricating independence.
4. Apply explicit ownership, barriers, structured handoffs, bounded retry,
   conflict resolution, and one lead integration path.
5. Verify the actual final artifacts with profile evidence, review named
   risks only, reconcile every requirement, clean owned temporary state, and
   stop under the Completion Contract.

There is no mandatory model pair, fixed phase count, external wrapper, approval
ritual, test suite, review count, or worktree script. Git and external mutations
remain separately authorized.
